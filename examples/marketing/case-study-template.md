# Case Study Template

Used to write up a finished project for the portfolio site and [[Instagram
Strategy]] posts.

Sections: the problem, the process (reference the relevant phase of the [[Brand
Discovery Process]]), three to five key visuals, one client quote, and results if
measurable (e.g. sales lift, press mentions).

Requires written client sign-off before publishing. [[Jamie Chen]] sends the sign-off
request as part of the [[Onboarding Checklist]] handoff step, not after the fact.
